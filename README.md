# Cap sur le DE — fiches de révision ST2

Fiches de révision condensées et interactives pour 5 matières :

- Ethical Hacking
- Sécurité Réseaux
- Sécurité des Systèmes d'exploitation
- Sécurité des Systèmes d'information
- Virtualisation & Stockage

Chaque fiche contient : l'essentiel hiérarchisé, les tableaux de comparaison, les pièges d'examen, un quiz, des flashcards et les questions ouvertes d'annales corrigées.

## Utilisation

Ouvrir `index.html` ou servir le dossier :

```bash
python3 -m http.server 8000
```

Puis aller sur `http://localhost:8000`.

## Déploiement

Le site est statique (HTML/CSS/JS), sans dépendance externe. Il est prévu pour GitHub Pages (branche `main`, dossier racine).

## Notes

- Contenu de synthèse personnel, à vérifier avec les consignes et les documents officiels du cours.
- `build_search.py` régénère l'index de recherche après modification des pages.
- `assets/quiz-data.js` et `assets/flashcards.js` contiennent les banques de questions.
