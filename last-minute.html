La veille et le matin

Dernière minute.

Les 10 à 12 points qui doivent être dans ta tête avant d'entrer. Une page par matière, pas de nouveau contenu. Lis, récite, coche mentalement.

Revoir le plan
Mode d'emploi

Ne lis pas tout d'un coup. Prends une carte, lis-la, ferme l'écran, récite les points à voix haute, puis vérifie. Si un point ne sort pas, ouvre la fiche complète uniquement pour celui-là. Le matin : 15 minutes maximum, pas de nouvelle notion.

Ethical Hacking

  • 5 phases : recon → scan/énumération → accès → persistance → effacement des traces (+ rapport).
  • Passif = pas d'interaction (OSINT, WHOIS, Shodan, Google Dorks). Actif = Nmap, scan, connexion.
  • Nmap : -sV version, -O OS, -sS SYN, -p- tous les ports, --script NSE.
  • NSE : scripts Lua, catégories safe/auth/vuln/exploit, détection de CVE.
  • Metasploit : search, use, set RHOSTS, set LHOST, run, sessions -i.
  • Meterpreter : shell en mémoire, hashdump, migrate, getuid.
  • msfvenom : -p, LHOST, LPORT, -f, -o.
  • Reverse shell = cible → attaquant ; traverse mieux les NAT.
  • Brute force = toutes les combinaisons ; dictionnaire = liste de mots.
  • Défenses : MFA, hash bcrypt/Argon2, verrouillage, rate limiting, Fail2ban, logs 4625.
  • OWASP : A01 accès, A03 injection, A07 auth, A10 SSRF.
  • Rapport : synthèse, méthode, constats + CVSS, remédiation, annexes.
Si tu ne retiens qu'une chose : les 5 phases et les commandes Metasploit/Nmap. C'est le cœur du QCM et des questions ouvertes.

Sécurité Réseaux

  • DICP : disponibilité, intégrité, confidentialité, preuve.
  • DMZ : zone tampon entre Internet et LAN, défense en profondeur, services exposés.
  • Deux FW : double filtrage ; même marque = homogénéité ; marques différentes = diversité.
  • Règles : par zone, source/destination/port explicites, premier match, deny all + log.
  • Stateful : table de connexions, autorise established/related ; stateless : chaque paquet seul.
  • Proxy : rupture protocolaire, cache, filtrage, anonymisation. Reverse proxy : protection, load balancing, TLS.
  • IPsec : AH = intégrité sans chiffrement ; ESP = confidentialité + intégrité ; tunnel = VPN.
  • SPD = politique ; SAD = SA actives ; NAT-T = UDP 4500.
  • WEP = RC4 + IV 24 bits + CRC-32 → cassé. WPA2-Enterprise = 802.1X + RADIUS.
  • PEAP vs TTLS : TTLS ouvert/flexible ; PEAP très Windows ; certificat serveur obligatoire.
  • IDS alerte (passif) ; IPS bloque (inline). Placement : entre FW1 et DMZ, puis avant le LAN.
  • DDoS : le firewall ne suffit pas ; protection en amont (FAI, cloud scrubbing, IXP).
Si tu ne retiens qu'une chose : savoir écrire un tableau de règles de filtrage et justifier DMZ + deux firewalls.

Sécurité des OS

  • 4 principes : minimisation, moindre privilège, défense en profondeur, veille/maintenance.
  • umask 0027 → fichier 640, répertoire 750. Fichier par défaut 666, répertoire 777.
  • SUID = EUID du propriétaire ; find / -perm -4000 -type f. Sticky = /tmp.
  • SUID root : risque d'escalade ; surfaces = entrées, environnement, TOCTOU, shell. Réduire, auditer, capabilities.
  • Sudo : use_pty, requiretty, noexec, umask 0027, ignore_dot, env_reset. Wildcards = dangereux.
  • PAM = auth centralisée + politique mdp. SELinux/AppArmor = MAC + cloisonnement.
  • Sysctl : ASLR=2, kptr_restrict, dmesg_restrict, suid_dumpable=0, syncookies=1, rp_filter=1.
  • Buffer overflow : ASLR, NX/DEP, canary, PIE, RELRO ; Windows /GS, CFG, SafeSEH.
  • Windows : Winlogon = session ; LSASS = auth/token/secrets ; SRM = accès/audit.
  • UAC = token filtré + élévation ; MIC = niveaux Low/Medium/High/System.
  • Credential Guard = VBS ; LSA Protection = PPL ; désactiver WDigest.
  • EAL4+ = Common Criteria ; C2 = TCSEC. 4625 = échec logon.
Si tu ne retiens qu'une chose : la chaîne « mécanisme → attaque → conséquence → mesure » pour SUID, sudo, LSASS et buffer overflow.

Sécurité des SI

  • DICP + preuve.
  • RGPD : finalité, minimisation, durée, exactitude, intégrité/confidentialité, responsabilité.
  • Données de santé = sensibles ; AIPD ; CNIL 72 h ; droits des personnes.
  • Risque = V × I ; traitements : réduire, accepter, éviter, transférer.
  • ISO 27001 = SMSI ; 27002 = contrôles ; 27005 = risques ; 22301 = continuité.
  • EBIOS RM = 5 ateliers (cadrage, sources, scénarios stratégiques, opérationnels, traitement).
  • IAM : identifier, authentifier, autoriser, tracer ; RBAC, moindre privilège, revue des accès, MFA.
  • LDAP : DN/OU/CN, bind, LDAPS 636, pas d'anonymous bind.
  • PCA = activité en mode dégradé ; PRA = restauration du SI ; RTO/RPO.
  • Sauvegarde 3-2-1 + test de restauration + copie offline/immuable.
  • Cas : actifs → données/RGPD → menaces → vulnérabilités → impacts → risques → recommandations.
  • Phrase : « mesure X → principe Y → risque Z réduit ».
Si tu ne retiens qu'une chose : la grille d'audit en 8 étapes et la chaîne menace → vulnérabilité → impact → mesure.

Virtualisation & Stockage

  • Type 1 = bare metal (ESXi, Hyper-V, Proxmox, Xen, KVM) ; type 2 = hébergé (VirtualBox, Workstation).
  • Conteneur = noyau partagé, léger, isolation plus faible ; VM = OS complet, isolation forte.
  • vSwitch = switch virtuel ; VMkernel = réseau infra (vMotion, iSCSI, NFS).
  • 3 réseaux VMware : bridged, NAT, host-only.
  • Stockage : DAS bloc local, NAS fichier, SAN bloc dédié ; vSAN hyperconvergé.
  • VMFS = bloc VMware ; NFS = fichier ; VMDK = disque virtuel.
  • vMotion = CPU/RAM ; Storage vMotion = disque ; snapshot ≠ backup.
  • HA = redémarre ; DRS = équilibre ; FT = zéro downtime.
  • Docker : image (read-only), conteneur (writable), registry (Docker Hub).
  • Dockerfile : FROM obligatoire ; RUN, COPY, WORKDIR, EXPOSE, ENV, CMD.
  • Compose : services, image/build, ports, volumes, depends_on ; docker compose up -d.
  • Supprimer tous les conteneurs : docker rm -f $(docker ps -aq).
Si tu ne retiens qu'une chose : les 3 schémas type 1 / type 2 / conteneur et les définitions Docker. C'est tombé presque à l'identique.

Le matin de l'examen

  • Relis uniquement cette page, pas les fiches complètes.
  • Prépare ta convocation, carte d'identité, stylos, montre (sans montre connectée).
  • Arrive en avance, coupe le téléphone, range-le.
  • Lis tout le sujet avant de commencer : repère les questions faciles.
  • Commence par ce que tu maîtrises, garde 10 minutes de relecture.
  • QCM : réponds à tout, aucune case vide.
  • Questions ouvertes : structure en titres, mots-clés, exemples.
  • Si tu bloques : écris la définition, puis un exemple, puis une mesure. Ça débloque.
  • Ne réécris pas le cours : réponds à la question posée.
  • Garde ton calme : une question ratée ne coule pas l'examen.
Rappel : la note se gagne d'abord sur les questions faciles et les définitions. Ne commence pas par la question à 5 points qui te bloque.

Le mot de la fin

Tu n'as pas besoin de tout savoir. Tu as besoin de savoir ce qui tombe, de le restituer clairement et de relier les notions. Les fiches sont construites pour ça. Maintenant, ferme l'écran et récite : c'est là que ça rentre.
